Phi-Plugin 用户设置

以下选项为你的个人偏好展示，选择结果将用于对应图片渲染。

主题风格

当前：[0]默认

使用/myset theme <序号>修改，控制图片页面的整体视觉风格，仅影响你的个人渲染结果。

[0]默认

已选中

使用插件基础主题，使用随机曲绘作为背景。

[1]寒冬

在默认的基础上加入飘落雪花元素。

[2]使一颗心免于哀伤

飞萤之火自无梦的长夜亮起，绽放在终竟的明天。

[3]大师赛2

Phigros 大师赛第二赛季主题配色

[4]Milthm

所有词语，都是雨的旋律

B30统计数据展示

当前：[0]全部统计

使用/myset avgkind <序号>修改，控制 B30 均值条展示的数据，可按全部平均数、仅 B30平均数 或 百分比绝对位置。

[0]全部统计

已选中

展示在相近rks的玩家中全部成绩的平均值统计，信息最完整。将使用全部四种颜色区分不同的相对位置关系。

[1]仅 B30

展示在相近rks的玩家中只按 B30 成绩平均值统计，关注B30健康度。将使用前两个或后两个颜色，下个选项选择任意一个颜色时将同时使用与其对应的颜色

[2]仅 Top

展示玩家成绩在相近rks的玩家中所有成绩和仅考虑B30成绩中的排名百分比，展示格式：[Top： 全体 / B30]。将全部使用下个选项选择的颜色进行展示

[3]隐藏

不展示B30均值相关信息，界面更简洁。

B30均值条配色

当前：[2]蓝

使用/myset avgcolor <序号>修改，控制 B30 均值条的主色，用于快速区分你的展示偏好。

[0]红

高对比暖色，视觉冲击更强。

[1]金

[2]蓝

[3]绿

中性偏亮配色，整体观感更清新。

API功能开关

当前：[0]启用

使用/myset api <序号>修改，关闭后将不再使用在线查分平台相关功能。

[0]启用

已选中

允许插件使用在线查分平台相关能力。

[1]禁用

禁用在线查分平台能力，仅使用本地数据。

B30统计分析

当前：[0]显示

使用/myset B30分析 <序号>修改，控制 B30 图片末尾的谱面标签能力与等效 RKS 直方图。

[0]显示

已选中

在 B30 图片末尾显示谱面标签能力和等效 RKS 直方图。

[1]隐藏

隐藏完整的 B30 统计分析区域。

Phi-Plugin API 用户设置

以下设置会同步到查分平台账户权限。

数据收集同意

当前：[1]同意

控制是否同意插件收集你的游戏数据（如成绩、游玩时间等）用于统计分析和功能优化，帮助我们改进插件性能和用户体验。关闭后将同步禁用下方所有选项。

[1]同意

已选中

[0]拒绝

插件将仅使用本地数据，不会上传任何信息。

排行榜展示

当前：[1]同意

同意将你的成绩展示在在线排行榜中，供其他玩家查看和比较。

[1]同意

已选中

[0]拒绝

你的成绩将不会在排行榜中展示。

数据聚合

当前：[1]同意

同意将你的成绩数据匿名化后用于整体统计分析，分析结果将用于推分建议以及谱面分析、定位等功能。

[1]同意

已选中

[0]拒绝

拒绝将你的成绩数据用于统计分析，插件将不会使用你的数据进行任何形式的分析或报告。

玩家ID搜索

当前：[1]同意

同意其他玩家通过你游戏中的的玩家ID搜索到你的成绩信息，便于社交互动和成绩比较。

[1]同意

已选中

[0]拒绝

其他人将无法通过你的游戏ID搜索到你的成绩信息。

用户ID搜索

当前：[1]同意

控制是否同意使用用户ID进行绑定，其他玩家可以通过用户id获取到你的成绩信息

[1]同意

已选中

[0]拒绝

禁止使用用户ID获取存档，将禁用用户ID绑定功能。
